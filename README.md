# Curiosity Lab

世界を知ることを、娯楽に。iPhone向けの、小さな知識探検博物館。

## 動作する機能

13テーマ・8分野、ジャンルと時間による探索、ランダム発見、全文検索、写真付き記事、関連記事、保存コレクション、タップできる知識星図、閲覧履歴に応じた星の変化、3つの操作実験（振り子・同時対比・確率）、自然な再遭遇、30秒雑談コピー、4モードのGPTブリッジ、部分選択、データの書き出し/読み込み、PWAとオフラインキャッシュ。

動画はTED-Ed公式2本。埋め込み可否は配信元や環境に依存するためYouTubeへの代替リンク付き。実視聴による100点評価は未完了で採点保留。記事の写真はイメージで、対象の正確な観察写真ではありません。

保存はlocalStorageです。端末をまたぐ同期やNotionへの自動転送は未実装です。アプリ内対話は採用せず、GPTブリッジで連携します。ChatGPTへの引き継ぎにAPIキーは不要です。

## GitHub Pagesに公開

1. GitHubで新規リポジトリ `curiosity-lab` を作成。
2. このソース全体をmainブランチへpush。`dist`だけでなく、`scripts`と`.github/workflows`も必要。
3. Settings → Pages → Sourceを **GitHub Actions** に設定。
4. Actions → Publish museum を実行。成功後のEnvironment URLが正式な公開先。
5. iPhoneのSafariでURLを開き、共有 → ホーム画面に追加。

アセット、manifest、Service Workerはすべて相対パスのためサブパスのGitHub Pagesにも対応します。`.openai/hosting.json`はWorkでの公開用で、GitHub Pagesには影響しません。

## 自動追加

`refresh.yml` は毎週月・水・金の日本時間7:00に実行（GitHub側の遅延はあり得ます）。事前確認済み追加記事は現在5本。1回に1件だけ公開します。枯渇時は既存展示を変更せず停止します。完全無制限に記事が増える仕組みではありません。

継続生成を使う場合：リポジトリのSettings → Secrets and variables → Actionsで `OPENAI_API_KEY` をSecretとして設定。任意のRepository variable `OPENAI_MODEL`（未設定時 `gpt-4.1-mini`）。ChatGPTの有料契約とは別のAPI従量課金です。実料金は利用モデルや本文長に依存します。現在キーは設定しておらず、API実通信は未検証です。

生成は `source-bank.json` の未使用の一次資料から、少ない分野を優先して1テーマずつ作成。取得した本文に基づく生成→別呼び出しで事実照合→スキーマ/出典/重複/画像/関連リンク検査→一括置換の順です。自動照合は誤情報を完全に保証しないため、定期的な人の確認を推奨します。出典取得や検証失敗時は公開ファイルを更新しません。既存URLと同じ資料は再利用しません。資料バンクを使い切った場合も安全に停止します。候補の追加にはURLのホストが `check.mjs` の許可リストにあることが必要です。

キーをフロントエンドに入れないでください。ブラウザーはAPIを直接呼びません。生成内容はHTMLとして解釈せずエスケープして表示します。外部資料は命令として実行しません。

## 検証

Node.js 22以上、依存パッケージ不要。

```sh
node scripts/check.mjs
node --test scripts/update.test.mjs
node scripts/update.mjs --dry-run
```

更新テスト：分野バランス、同一出典排除、不十分な根拠の拒否、画像や関連リンクの欠損拒否、失敗時の既存ファイル保全、確認済み記事1件の追加。Service Workerは接続成功時にネットワークの最新版を優先し、失敗時にキャッシュを表示します。

## 再遭遇

初回閲覧から3日後以降、トップに異なる観察の切り口を表示。同じ展示は再遭遇から7日間空けます。通知・テスト・連続ログイン報酬はありません。

## 現状の制約

- GitHubへのソース反映と公開ワークフローの接続は完了。公開状況はActionsの実行結果で確認できます。
- 動画の全編視聴評価、iPhone実機・Safari固有の検証は未実施。
- アプリ内対話は対象外。GPTブリッジは実装済み。
- ローカル保存はブラウザーのデータ削除で失われます。書き出しを利用できます。
- 星図の関連線は編集時に設定した意味関係です。自動で新しい科学的関係を発見する機能ではありません。
