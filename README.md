# Curiosity Lab

世界を知ることを、娯楽に。iPhone向けの、小さな知識探検博物館。

## 動作する機能

新しい8展示室：衣類と洗濯／料理の基本／道具のしくみ／伝わる言葉／感じ方の不思議／文明と暮らし／自然の戦略／遊びの奥側。

衣類3種類の畳み方と2品の練習レシピを、手順図と前後ボタンで表示。波の打ち消し・干す間隔・背景と擬態・回転と軌道・言い換え・比較軸の切り替えを追加。図は教材用の模式図で、実物の物理計算や手元動画ではありません。

27テーマ・8分野＋8つのテーマ展示室、ジャンルと時間による探索、ランダム発見、全文検索、写真付き記事、関連記事、保存コレクション、タップできる知識星図、閲覧履歴に応じた星の変化、24種類・8ジャンルの操作体験、自然な再遭遇、30秒雑談コピー、4モードのGPTブリッジ、部分選択、データの書き出し/読み込み、PWAとオフラインキャッシュ。

全27展示に日本語の参考動画を配置。日本語音声、日本語字幕、日本語解説付き観察映像を明示。記事内と動画展示室の両方からアクセスできます。関連テーマの映像は補足であることを明記。埋め込み可否は配信元や環境に依存するためYouTubeへの代替リンク付き。実視聴による100点評価は未完了で採点保留。記事の写真はイメージで、対象の正確な観察写真ではありません。

保存はlocalStorageです。端末をまたぐ同期やNotionへの自動転送は未実装です。アプリ内対話は採用せず、GPTブリッジで連携します。ChatGPTへの引き継ぎにAPIキーは不要です。

## GitHub Pagesに公開

1. GitHubで新規リポジトリ `curiosity-lab` を作成。
2. このソース全体をmainブランチへpush。`dist`だけでなく、`scripts`と`.github/workflows`も必要。
3. Settings → Pages → Sourceを **GitHub Actions** に設定。
4. Actions → Publish museum を実行。成功後のEnvironment URLが正式な公開先。
5. iPhoneのSafariでURLを開き、共有 → ホーム画面に追加。

アセット、manifest、Service Workerはすべて相対パスのためサブパスのGitHub Pagesにも対応します。`.openai/hosting.json`はWorkでの公開用で、GitHub Pagesには影響しません。

## 自動追加

月・水・金の日本時間7:00に `refresh.yml` が動きます。登録済みのお気に入り12チャンネルの動画フィードと過去の編集候補を照合し、既存教材にない動画をActions成果物 `video-candidates` にまとめます。フィードから得られる候補は調査用です。各エピソードのおおもとの動画、公開された採録または実演を確認し、日本語の裏付け資料を添えます。

`scripts/video-bank.json` には内容確認を通った個別動画を登録します。先頭の動画が元動画です。`videoOrigin` に公開元、確認した内容、確認資料を入れ、対応する既存実験があれば `labs` に指定します。OpenAI APIキーが設定されている場合、公開済み動画IDで重複を除き、お気に入り・少ない分野の順に教材を下書きし、別のAPI呼び出しで資料との照合を行います。APIキーはリポジトリのActions Secret `OPENAI_API_KEY` で設定し、既定モデルは `gpt-4.1-mini` です。

各回は、確認済みの動画教材または事前編集された待機教材を1件ずつ、日本語資料、元動画と補足動画の応答、内容の長さ、関連リンクを検査してから公開します。動画フィードだけからの教材化や、利用できる資料がない状態での公開は行いません。リンクの検査はHTTP応答とYouTubeの動画メタデータを確認するものです。視聴地域、期間制限、字幕および映像の再生状況は配信元に依存します。

## 検証

Node.js 22以上、依存パッケージ不要。

```sh
node scripts/check.mjs
node --test scripts/update.test.mjs
node scripts/update.mjs --dry-run
```

各記事は6節構成で本文約820〜900字（要約・図解・動画は別）。一律の5分表記を廃止し、要約と本文を1分350字で読了目安に換算。背景までを初期表示し、目次と要点表示も利用できます。

公開検査は5節以上・本文800字以上、日本語参考資料と確認済み日本語動画を必須とします。文字数は最低限の形式検査であり、内容の正しさや十分さの保証ではありません。新規生成では1200字以上を指示しています。

更新テスト：分野バランス、同一出典排除、不十分な根拠の拒否、画像や関連リンクの欠損拒否、失敗時の既存ファイル保全、確認済み記事1件の追加。Service Workerは接続成功時にネットワークの最新版を優先し、失敗時にキャッシュを表示します。

## 再遭遇

初回閲覧から3日後以降、トップに異なる観察の切り口を表示。同じ展示は再遭遇から7日間空けます。通知・テスト・連続ログイン報酬はありません。

## 現状の制約

- GitHubへのソース反映と公開ワークフローの接続は完了。公開状況はActionsの実行結果で確認できます。
- 動画の全編視聴評価、iPhone実機・Safari固有の検証は未実施。
- アプリ内対話は対象外。GPTブリッジは実装済み。
- ローカル保存はブラウザーのデータ削除で失われます。書き出しを利用できます。
- 星図の関連線は編集時に設定した意味関係です。自動で新しい科学的関係を発見する機能ではありません。


## チャンネルからの探検（v1.3）

`#channels`：好きな12チャンネルと提案18チャンネル、合計30件を登録。ジャンル・図解／実物／対談／講座・名前やテーマで絞り込み、ラボ内のチャンネル保存、偶然の発見、関連展示・展示室への寄り道、出典付きGPT質問文コピーができます。トップと動画展示室、保存コレクションからアクセスできます。

`#watch`：公開メタデータで題名と発信元を確認した6本の入口動画。入門と深掘りを切り替え、チャンネルごとの入口にも移動できます。既存の全27展示の日本語参考動画は `#videos` に引き続き表示します。記事にも別の語り手への関連案内を表示します。内容の直接的な根拠と、関連テーマとしての紹介は区別します。

チャンネル情報は `dist/channels.json` の編集データです。全動画の正確性・品質を保証するものではなく、全編の100点評価は未実施。未確認の点数や再生時間、最新動画の自動取得は表示しません。選定動画をYouTube公式の埋め込みと公式視聴リンクで開きます。APIキー・追加料金は不要。外部視聴には通信が必要です。

保存チャンネルは既存localStorageデータの `channelSaves` 配列で保持し、既存の記事保存と履歴を保持。データの書き出し・読み込みに対応し、旧形式のファイルも受け付けます。新カタログはPWAキャッシュ対象。取得失敗時も既存の展示を表示します。


## 更新状況の確認（v1.4 / 2026-11-24）

トップと設定に、最終追加日、展示数、新着記事、配信候補数を表示。配信待ちの情報は `dist/update-status.json` を更新処理が生成します。月・水・金7時は実行予定で、実行遅延があり得ます。候補切れ・追加失敗時はActionsの最終ステップも失敗扱いにし、既存記事と更新状態だけを公開します。失敗を「新規追加成功」として扱いません。キー不要の確認済み候補配信です。

「最新情報を確認」と、アプリを再び表示した際の再取得に対応。読書中の自動再取得は避け、保存と履歴は保持します。アプリ本体に新しい版が届いた場合は「新しい画面に更新」ボタンを表示します。オフラインで返すキャッシュには識別用ヘッダーを付け、手動確認で通信成功と誤表示しません。旧版から初めて切り替える際は再読み込みが必要な場合があります。


## 実験室の拡張（v1.5 / 2026-11-25）

実験室を3種類から24種類へ拡張。各ジャンル3種類ずつ収録しています。

- 社会と制度：ドント式、予算の配分、多数決の循環
- 言葉と対話：情報の順番、修飾の範囲、成功と失敗の見出し
- 歴史と文化：地方時、交換と共通の券、架空資料の読み分け
- 芸術とデザイン：RGB、一点透視、構図と余白
- 暮らしと料理：長方形の収納、レシピの比例、家事の並列工程
- 心理とデータ：平均と中央値、基準率、集計の逆転
- 自然と生きもの：背景と擬態、二型の世代変化、最小律の樽
- 科学と偶然：従来の振り子、同時対比、コインの確率

`dist/lab-catalog.js` が展示メタデータ、`dist/labs.js` が描画と計算、`dist/lab.css` が画面を担当します。`#lab` が一覧、`#lab-<id>` が個別体験。ジャンル絞り込み、偶然の入口、21の新規体験の条件比較・リセット・観察結果と出典を含むGPTコピーに対応。条件と比較はページを開いている間のみ保持し、再読み込みで消えます。既存の記事保存・閲覧履歴は保持します。クイズ・点数・性格診断は設けません。

全24体験に日本語の参考資料と参考映像を表示。関連映像は、模型そのものの説明とは区別して案内します。日本語の動画全編の実視聴採点は未完了。架空の資料、単純な算術模型、理想化したモデルの前提を各画面に明示し、現実の社会・生物の結果を断定的に予測しません。

検証は、ドント式の公的な計算例、同じ投票者での勝者の変化、条件付き確率の分母、平均・中央値、収納枚数・工程時間・中立な選択条件の不変性、全操作の両端、全ルート・日本語メディアの接続を含みます。PWAのキャッシュ対象に3つの新ファイルを追加しています。
